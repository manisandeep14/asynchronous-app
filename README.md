# Weather Dashboard

A responsive weather application built using:

- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await
- Local Storage

## Features

- Search weather by city
- Current temperature
- Humidity
- Wind speed
- Feels like temperature
- Search history
- Duplicate prevention
- Error handling
- Responsive design

## Concepts Practiced

- DOM Manipulation
- Fetch API
- Async/Await
- Promises
- Local Storage
- Event Handling
